# 04 资源清单（美术 / 动画 / 音频 / UI）

> 本清单是采购与外包的数量依据，与文档 03 的 ART/AUD 任务、文档 06 的交付规范配套。
> 所有资源入库前必须满足文档 06 的命名、尺寸、锚点、格式规范，否则 QA 拒收。

## 1. 通用技术规格

| 项 | 规格 |
|---|---|
| 引擎 | Godot 4.7.2，GLES/Compatibility 渲染（兼容低端机） |
| 设计分辨率 | 1280×720，像素单位以 64px 为一格（地面 tile 基准） |
| 角色源尺寸 | 单帧画布 **256×256 px**，角色脚底锚点居中（128, 240），四周留 8–16px 安全边 |
| Boss 源尺寸 | 单帧画布 **384×384 px**（最终 Boss 拜登 512×512） |
| 场景背景 | 分层 PNG，单层 1280×720；整关宽度按 3680px 世界宽度平铺，提供可平铺元件 |
| 颜色 | sRGB；角色带统一 2–4px 深色描边；透明背景 PNG |
| 源文件 | Aseprite(.aseprite) 或 PSD 同时交付，便于改帧 |
| 帧率 | 动画 12–15fps（像素/漫画风），交付时附帧时长表 |
| 方向 | 角色至少 4 方向（上/下/左/右），左右可镜像，上下需单独绘制纵深姿态 |
| 音频 | SFX：WAV 48kHz/16bit 单声道；BGM：WAV 48kHz 立体声 + OGG 压缩版；配音 WAV 48kHz |
